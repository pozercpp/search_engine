# Поисковый движок на C++ (с BM25)

![C++](https://img.shields.io/badge/C%2B%2B-20-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-ready-brightgreen)

**Полноценный текстовый поисковый движок**, написанный на современном C++20.  
Поддерживает:
- Быструю индексацию тысяч документов
- Алгоритм ранжирования **BM25** (как в Elasticsearch)
- Сохранение и загрузку индекса (JSON)
- Булевы запросы: `AND`, `OR`
- Очистку текста, стоп-слова, позиции слов

Идеально подходит для:
- Локального поиска по документам
- Обучения информационному поиску
- Прототипирования поисковых систем

В дальнейшем планирую добавить многопоточность

---

### Возможности

| Функция                    | Статус     | Описание |
|---------------------------|------------|---------|
| Рекурсивная индексация     | Done       | Все `.txt`, `.md`, `.html` и др. |
| Стоп-слова                 | Done       | Загружаются из файла |
| Обратный индекс            | Done       | `term → doc_id, freq, positions` |
| BM25 ранжирование          | Done       | Профессиональный скор |
| Сохранение индекса         | Done       | JSON (легко читается) |
| Быстрая загрузка           | Done       | Не нужно индексировать каждый раз |
| Интерактивный поиск        | Done       | Вводи запросы в консоль |
